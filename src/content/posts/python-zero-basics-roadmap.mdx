## Python 代码到底在做什么

先不要记语法。看下面这段只有 8 行的代码：

```python
orders = [
    {"order_no": "A001", "amount": 129.0, "status": "已支付"},
    {"order_no": "A002", "amount": 88.0, "status": "已退款"},
]

for order in orders:
    if order["status"] == "已支付":
        print(order["order_no"], order["amount"])
```

零基础读者暂时不需要解释每个符号，先沿着运行顺序观察：

<ol class="py-runtime-trace" aria-label="订单脚本运行顺序">
  <li><span>输入</span><strong>读取两条订单</strong><small>列表保存整批数据</small></li>
  <li><span>逐条处理</span><strong>每次拿出一条订单</strong><small><code>for</code> 控制处理节奏</small></li>
  <li><span>判断</span><strong>状态是否为“已支付”</strong><small><code>if</code> 决定是否继续</small></li>
  <li><span>输出</span><strong>打印订单号和金额</strong><small>未通过的订单不会输出</small></li>
</ol>

后面的几篇文章，本质上就是把这 8 行代码拆开：

| 代码片段 | 后面会学什么 |
| --- | --- |
| `"A001"`、`129.0` | 字符串、数字和基础类型 |
| `[...]` | 列表：保存多条同类数据 |
| `{...}` | 字典：保存一条数据的多个字段 |
| `for` | 循环：一条一条处理 |
| `if` | 判断：决定当前数据要不要处理 |
| `print()` | 函数调用：让 Python 执行动作 |

这也是学习 Python 最重要的习惯：**不要把代码看成一大段符号，要看它每一步拿到了什么数据，又把数据变成了什么。**

## 按任务学习，而不是背语法目录

这个系列先问“任务需要什么”，再引出语法：一条数据用变量，多条数据用列表，一条订单的多个字段用字典；`if` 决定是否处理，`for` 负责逐条处理，函数收纳重复逻辑，文件、JSON 和异常负责接入外部数据。

每遇到一段新代码，固定做四件事：

1. 先不运行，猜它会输出什么。
2. 再运行，看看和自己的判断是否一致。
3. 修改一个值、一个条件或一条数据，再运行一次。
4. 用自己的话说清楚“数据从哪里来，经过了什么，最后去了哪里”。

例如：

```python
stock = 3

if stock < 5:
    print("需要补货")
```

把 `stock` 改成 `8`，观察为什么没有输出；再加一个 `else`，确认两条分支只会执行其中一条。这样的修改比只记住“`if` 是判断”更有效。

## 第一次把 Python 真正跑起来

如果你已经能运行 Python 3，这一节可以快速跳过。先在终端里试：

```bash
python --version
```

macOS / Linux 更常见的是：

```bash
python3 --version
```

Windows 也可以试：

```bash
py --version
```

只要其中一个命令能看到 Python 3 的版本号，就已经可以开始。

如果三个命令都不可用，先安装 Python 3，再重新打开终端确认版本。这里不展开 IDE、虚拟环境和包管理，零基础第一步只需要完成一个最小闭环：

<ol class="py-first-run" aria-label="第一次运行 Python 脚本的三个步骤">
  <li><span>01</span><strong>创建文件</strong><code>demo.py</code><small>放在自己找得到的文件夹</small></li>
  <li><span>02</span><strong>写入并保存</strong><code>print("Hello Python")</code><small>确认扩展名是 .py</small></li>
  <li><span>03</span><strong>在终端运行</strong><code>python demo.py</code><small>也可以使用 python3 / py</small></li>
</ol>

例如 `demo.py`：

```python
print("Hello Python")
```

进入这个文件所在目录后运行：

```bash
python demo.py
```

如果你的环境使用的是 `python3` 或 `py`，把命令里的 `python` 换掉即可。

看到：

```text
Hello Python
```

就说明环境已经够用了。编辑器可以使用你已经熟悉的工具，这个系列不会把重点放在 IDE 配置上。

## 学完以后能做什么

学完整套基础，你还不会突然变成 Python 工程师，但应该已经能进入下面这些方向，而不是重新从“什么是变量”开始：

| 方向 | 下一步会接触什么 | 当前系列提供的基础 |
| --- | --- | --- |
| 数据处理 | CSV、Excel、pandas | 列表、字典、循环、文件 |
| RPA / 自动化 | 页面操作、任务流程、结果处理 | 判断、循环、函数、异常 |
| API 调用 | HTTP 请求、鉴权、接口字段 | JSON、字典、异常、函数 |
| 简单脚本 | 批量重命名、整理文件、定时任务 | 文件、循环、函数 |
