如果你学 Python 的目标不是参加算法竞赛，而是想处理 Excel 导出的数据、写 RPA 辅助脚本、调用 API，或者把重复操作变成一段自动执行的代码，那么入门顺序应该围绕一个问题展开：**数据进来以后，Python 到底怎么一步一步把它变成结果？**

这个系列不会把 Python 写成一门计算机专业课程。我们只先学习以后真正会反复用到的部分，并且每篇都尽量让代码落在订单号、SKU、状态判断、JSON、文件这些真实场景里。

</HighlightBox>

## Python 代码到底在做什么

先不要记语法。看下面这段只有 8 行的代码：

```python
orders = [
    {"order_no": "A001", "amount": 129.0, "status": "已支付"},
    {"order_no": "A002", "amount": 88.0, "status": "已退款"},
]

for order in orders:
    if order["status"] == "已支付":
        print(order["order_no"], order["amount"])
```

零基础读者暂时不需要把每个符号都解释出来。先抓住数据流：

```text
两条订单数据
    ↓
一条一条取出来
    ↓
判断状态是不是“已支付”
    ↓
符合条件才输出订单号和金额
```

后面的几篇文章，本质上就是把这 8 行代码拆开：

| 代码片段 | 后面会学什么 |
| --- | --- |
| `"A001"`、`129.0` | 字符串、数字和基础类型 |
| `[...]` | 列表：保存多条同类数据 |
| `{...}` | 字典：保存一条数据的多个字段 |
| `for` | 循环：一条一条处理 |
| `if` | 判断：决定当前数据要不要处理 |
| `print()` | 函数调用：让 Python 执行动作 |

这也是学习 Python 最重要的习惯：**不要把代码看成一大段符号，要看它每一步拿到了什么数据，又把数据变成了什么。**

## 这套系列为什么不按“语法大全”来学

传统入门资料很容易按语法目录展开：变量、运算符、列表、元组、集合、函数、类……每一项都解释一遍。这样当然完整，但新手常常出现一种情况：每个词都见过，真正给一份订单列表却不知道从哪里开始。

这个系列会反过来组织内容。

先问任务需要什么：

```text
我有一条数据 → 用变量保存
我有很多条数据 → 用列表
一条订单有很多字段 → 用字典
只处理部分订单 → 用 if
每条都要处理 → 用 for
同一套逻辑会反复用 → 写成函数
数据来自文件或接口 → 处理文件 / JSON / 异常
```

语法仍然会学，但每个语法都要知道“什么时候用”。

## 每篇文章各自负责什么

### 01｜学习路线

就是你正在看的这一篇。先建立整套地图，知道每个知识点为什么存在。

### 02｜变量与基础数据类型

只解决“一份值是什么”的问题：字符串、整数、小数、布尔值、`None`、变量、比较和类型转换。

你会看懂这类代码：

```python
sku = "K161"
price = 129.0
stock = 8
is_available = stock > 0
```

### 03｜字符串、列表、字典与常用容器

解决“真实数据怎么组织”的问题。重点不是背八种容器，而是先熟练字符串、列表和字典，再知道元组、集合什么时候有用。

```python
product = {"sku": "K161", "stock": 8}
products = [product]
```

### 04｜条件判断与循环

让代码开始“做决定”和“重复处理”。这一篇会重点画出变量在循环里的变化，而不是只告诉你 `for` 的写法。

```python
for product in products:
    if product["stock"] < 5:
        print(product["sku"], "需要补货")
```

### 05｜函数与代码拆分

当一段逻辑已经跑通，下一步不是立刻写类，而是先把明确的小步骤变成函数。

```python
def need_restock(stock):
    return stock < 5
```

这一篇会重点讲清 `return` 和 `print()` 的区别、参数怎么进入函数，以及为什么可变默认参数会留下状态。

### 06｜文件、JSON 与异常处理

这是从“练习代码”走向“真实脚本”的关键一步。因为自动化数据很少永远写死在代码里，它们通常来自文件或接口返回结果。

```text
TXT / JSON 文件 ─┐
                 ├─→ Python 数据 → 清洗 / 判断 → 结果
API 返回 JSON ───┘
```

### 07｜类与基础面向对象

只学真正需要理解的基础：`class`、对象、`__init__`、`self`、属性和方法，以及什么时候其实继续用“字典 + 函数”更简单。

### 08｜Python 基础综合考核

最后用现有 20 道题检查是否真正越过“看过语法”的阶段。里面会出现类型转换、循环、字典、函数、异常、文件、JSON、类、浅拷贝和默认参数。

## 学习时不要只看代码

每遇到一段新代码，可以固定做四件事：

1. 先不运行，猜它会输出什么。
2. 再运行，看看和自己的判断是否一致。
3. 修改一个值、一个条件或一条数据，再运行一次。
4. 用自己的话说清楚“数据从哪里来，经过了什么，最后去了哪里”。

例如：

```python
stock = 3

if stock < 5:
    print("需要补货")
```

不要只记住“`if` 是判断”。可以把 `stock` 改成 `8`，观察为什么什么都不输出；再加一个 `else`，看两条分支如何只执行其中一条。

## 最小运行环境

这个系列默认你已经有一个可以运行 Python 3 的环境。先确认：

```bash
python --version
```

部分 macOS / Linux 环境需要使用：

```bash
python3 --version
```

只要能看到 Python 3 的版本号，就可以把代码保存成例如 `demo.py`，再运行：

```bash
python demo.py
```

或：

```bash
python3 demo.py
```

编辑器可以用你已经熟悉的工具。这个系列不会把重点放在 IDE 配置上，因为真正需要建立的是代码运行直觉。

## 学完以后能做什么

学完整套基础，你还不会突然变成 Python 工程师，但应该已经能进入下面这些方向，而不是重新从“什么是变量”开始：

| 方向 | 下一步会接触什么 | 当前系列提供的基础 |
| --- | --- | --- |
| 数据处理 | CSV、Excel、pandas | 列表、字典、循环、文件 |
| RPA / 自动化 | 页面操作、任务流程、结果处理 | 判断、循环、函数、异常 |
| API 调用 | HTTP 请求、鉴权、接口字段 | JSON、字典、异常、函数 |
| 简单脚本 | 批量重命名、整理文件、定时任务 | 文件、循环、函数 |
