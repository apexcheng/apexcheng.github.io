## 变量不是“一个盒子”，更像一个名字

```python
stock = 8
```

入门时可以把它理解成：“给数字 `8` 起了一个名字叫 `stock`。”

更准确一点说，Python 创建了整数对象 `8`，变量名 `stock` 指向它。现在只要记住：**变量名和变量保存的值不是一回事。**

```python
sku = "K161"
```

这里：

- `sku` 是变量名。
- `"K161"` 是字符串值。
- `=` 不是数学里的“等于”，而是把右边的值绑定给左边的变量名。

所以：

```python
stock = 8
stock = 5
```

第二行执行以后，`stock` 现在代表的是 `5`。

## `str`：订单号、SKU、状态都通常是字符串

字符串就是文本数据，用引号包起来：

```python
order_no = "JD20260822001"
sku = "K161"
status = "已支付"
```

即使内容全是数字，只要加了引号，它仍然是字符串：

```python
order_no = "1008611"
```

不要因为看起来像数字，就急着转成 `int`。订单号、手机号、SKU 这类字段通常是**标识**，不是拿来做加减乘除的数字。

输出字符串时推荐使用 f-string：

```python
stock = 8
print(f"当前库存：{stock}")
```

```python
sku = "K161"
stock = 8
print(f"{sku} 当前库存 {stock} 件")
```

输出：

```text
K161 当前库存 8 件
```

## `int` 和 `float`：真正参与计算的数字

```python
quantity = 2
price = 129.9
amount = quantity * price

print(amount)
```

输出：

```text
259.8
```

`int` 是整数，`float` 是浮点数，也就是日常说的小数。

| 值 | 类型 | 适合表示 |
| --- | --- | --- |
| `2` | `int` | 件数、次数、库存 |
| `129.9` | `float` | 单价、金额、比例 |
| `"2"` | `str` | 文本形式的数字，还不能直接参与数值运算 |

除法 `/` 即使两个数都是整数，结果也会是浮点数：

```python
print(10 / 2)
```

结果是：

```text
5.0
```

## `bool`：很多判断最后都会变成 True 或 False

```python
stock = 3
is_low_stock = stock < 5

print(is_low_stock)
```

输出：

```text
True
```

这里不是手工写入 `True`，而是 `stock < 5` 计算出了布尔值。常见比较有：

```python
stock == 0      # 是否等于 0
stock != 0      # 是否不等于 0
stock > 5       # 是否大于 5
stock >= 5      # 是否大于等于 5
stock < 5       # 是否小于 5
stock <= 5      # 是否小于等于 5
```

注意：判断相等用 `==`，赋值用 `=`。

```python
status = "已支付"          # 赋值
status == "已支付"         # 判断，结果是 True 或 False
```

这两个符号是新手非常常见的混淆点。

## `None`：不是空字符串，也不是 0

真实数据里经常会遇到“暂时没有值”：

```python
tracking_no = None
```

`None` 表示没有具体值，和下面这些值都不同：

```python
""      # 空字符串
0       # 数字零
False   # 布尔假值
None    # 没有值
```

以后处理 JSON、API 或缺失字段时，会经常遇到它。

判断是否为 `None`，通常写：

```python
if tracking_no is None:
    print("还没有物流单号")
```

`if` 会在后面的条件判断文章里完整展开，这里只需要认识写法。

## 看类型并诊断转换错误

```python
sku = "K161"
stock = 8
price = 129.9

print(type(sku))
print(type(stock))
print(type(price))
```

你会看到类似：

```text
<class 'str'>
<class 'int'>
<class 'float'>
```

如果一个字段“看起来像数字却算不了”，先用 `type()` 确认它的真实类型。最常见的错误就是把文本形式的数字直接拿去计算：

```python
price = "119.9"
quantity = "2"

print(price * quantity)
```

这会报错。原因不是 Python 不会乘法，而是两个变量都是字符串。

把它们转成真正的数字：

```python
price = float("119.9")
quantity = int("2")

amount = price * quantity
print(amount)
```

输出：

```text
239.8
```

常见转换函数只有三种需要先记住：

```python
int("20")       # 20
float("19.9")   # 19.9
str(20)          # "20"
```

但转换不是“强制成功”：

```python
int("K161")
```

这会报 `ValueError`，因为 `K161` 不是一个合法整数。

以后处理外部文件或接口数据时，我们会用异常处理来接住这类情况。

## 一次看懂数据状态怎么变化

下面这段代码模拟一个从文本读到库存数字，再计算库存状态的过程：

```python
raw_stock = "3"
stock = int(raw_stock)
is_low_stock = stock < 5
message = f"库存：{stock}，需要补货：{is_low_stock}"

print(message)
```

<ol class="py-state-flow" aria-label="库存数据状态变化">
  <li><span>01 · 输入</span><code>raw_stock = "3"</code><small>来源是文本，所以类型为 str</small></li>
  <li><span>02 · 转换</span><code>stock = int(raw_stock)</code><small>得到可以比较的整数 3</small></li>
  <li><span>03 · 比较</span><code>stock &lt; 5</code><small>表达式得到布尔值 True</small></li>
  <li><span>04 · 输出</span><code>{'f"库存：{stock}…"'}</code><small>把结果组织成可读文本</small></li>
</ol>

这就是以后很多数据脚本的基本形态：**外部数据先进入 Python → 转成合适类型 → 做计算或判断 → 生成结果。**

## 目前只需要这些运算符

```text
+  -  *  /          # 基础算术
== != > >= < <=     # 基础比较
```

`//`、`%`、`**` 等运算符等遇到具体场景再补，不需要现在全部背完。

## 动手练习：一条订单的基础字段

先写：

```python
order_no = "A1001"
price = "129.9"
quantity = "2"
is_refunded = False

amount = float(price) * int(quantity)

print(f"订单号：{order_no}")
print(f"订单金额：{amount}")
print(f"是否退款：{is_refunded}")
```

然后自己完成三次修改：

1. 把数量改成 `"3"`，确认金额如何变化。
2. 把 `price` 直接改成数字 `129.9`，再调整计算代码。
3. 把 `is_refunded` 改成 `True`，观察输出。

如果你能解释每一个变量当前是什么类型、为什么这样转换，这一篇就已经达标。
