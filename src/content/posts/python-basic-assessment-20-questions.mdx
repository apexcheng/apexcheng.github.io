### 16｜坏金额怎样被记录后跳过

```python
raw_orders = [
    {"order_no": "A001", "amount": "129.0"},
    {"order_no": "A002", "amount": "未知"},
    {"order_no": "A003", "amount": "199.0"},
]

clean_orders = []
problems = []
total_amount = 0.0

for order in raw_orders:

        amount = float(order["amount"])
    except ValueError as error:

    clean_orders.append(order["order_no"])
    total_amount += amount
```
