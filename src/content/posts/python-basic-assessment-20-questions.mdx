- 建议用时：30～45 分钟。第一次独立完成时，不需要追求速度。

## 20 道完整题目

不需要先下载附件。下面四组可以直接展开做题；下载版只是方便你把答案写进一个 `.py` 文件里。

<details class="assessment-group" id="assessment-01-04" open>
  <summary><span>01–04</span><strong>基础数据处理</strong><small>类型、列表、字典、字符串</small></summary>

<div class="assessment-title"><b>01</b><strong>类型转换</strong></div>

已知商品单价和购买数量都是字符串。计算订单总金额，并输出 `总金额: 239.8`。结果必须来自数值计算，不能直接拼接字符串。

```python
price = "119.9"
quantity = "2"
```

<div class="assessment-title"><b>02</b><strong>列表、循环与条件</strong></div>

从 `scores` 中筛选所有大于等于 60 分的成绩，并计算这些及格成绩的平均分。期望得到 `[78, 92, 65, 88]` 和 `80.75`。

```python
scores = [45, 78, 92, 58, 65, 88]
```

<div class="assessment-title"><b>03</b><strong>字典统计</strong></div>

统计下面列表中每种商品出现的次数。期望得到 `{'键盘': 3, '鼠标': 2, '耳机': 1}`。

```python
products = ["键盘", "鼠标", "键盘", "耳机", "鼠标", "键盘"]
```

<div class="assessment-title"><b>04</b><strong>字符串处理</strong></div>

去除 `username` 首尾空格并转成小写，然后判断处理后的用户名是否等于 `"admin"`。

```python
username = "  Admin  "
```
</details>

<details class="assessment-group" id="assessment-05-12">
  <summary><span>05–12</span><strong>循环、函数与容器</strong><small>把基础语法组合成任务</small></summary>

<div class="assessment-title"><b>05</b><strong>函数与返回值</strong></div>

补全函数：金额大于等于 500 元时打 9 折，否则不打折。函数应返回最终金额。

```python
def calculate_total(amount):
    pass

print(calculate_total(600))  # 540.0
print(calculate_total(300))  # 300
```

<div class="assessment-title"><b>06</b><strong>去重与排序</strong></div>

删除重复用户 ID，并按从小到大排序。期望得到 `[101, 102, 103, 105]`。

```python
user_ids = [103, 101, 102, 101, 105, 103]
```

<div class="assessment-title"><b>07</b><strong>循环与条件</strong></div>

统计 `numbers` 中大于 10 的数字数量。

```python
numbers = [5, 12, 8, 20, 15, 3]
```

<div class="assessment-title"><b>08</b><strong>列表推导式</strong></div>

使用列表推导式生成平方列表 `[1, 4, 9, 16, 25]`。

```python
numbers = [1, 2, 3, 4, 5]
```

<div class="assessment-title"><b>09</b><strong>元组不可变</strong></div>

不运行代码，说明下面代码为什么会报错。

```python
data = ("Python", "SQL")
data[0] = "Java"
```

<div class="assessment-title"><b>10</b><strong>集合去重</strong></div>

使用集合去除重复数据，并输出去重后的结果。

```python
tags = ["AI", "Python", "AI", "RPA"]
```

<div class="assessment-title"><b>11</b><strong><code>*args</code></strong></div>

补全函数，使它能接收任意数量参数并计算总和。

```python
def total(*args):
    pass

print(total(10, 20, 30))
```

<div class="assessment-title"><b>12</b><strong>异常处理</strong></div>

使用 `try / except` 处理除数为 0 的情况。

```python
a = 10
b = 0
```

读取并打印 `test.txt`。如果在本地做题，请先下载页面顶部提供的测试素材并和 Python 文件放在同一目录。

把下面字典转换成 JSON 字符串。

user = {"name": "张三", "age": 20}

使用 `pathlib` 输出当前工作目录。要求写出正确的 import，并调用 `Path.cwd()`。

<div class="assessment-title"><b>17</b><strong>综合数据处理</strong></div>

根据下面订单数据统计销售总金额。

orders = [
    {"name": "键盘", "price": 100, "count": 2},
    {"name": "鼠标", "price": 50, "count": 3},
]

<div class="assessment-title"><b>18</b><strong>变量引用</strong></div>

不运行代码，写出两个 `print` 的结果并说明原因。

```python
a = [1, 2]
b = a
b.append(3)

print(a)
print(b)
```

<div class="assessment-title"><b>19</b><strong>浅拷贝</strong></div>

不运行代码，写出两个 `print` 的结果，并解释为什么修改 `copy_data["skills"]` 会影响 `original`。

```python
original = {
    "name": "张三",
    "skills": ["Python", "SQL"],
}

copy_data = original.copy()
copy_data["name"] = "李四"
copy_data["skills"].append("Linux")

print(original)
print(copy_data)
```

<div class="assessment-title"><b>20</b><strong>可变默认参数</strong></div>

不运行代码，写出两次调用的输出结果并说明原因。

```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("A"))
print(add_item("B"))
```

## 怎么判断完成质量

不需要强行要求所有人写出完全相同的代码。按下面四项评估：

<ol class="assessment-rubric">
  <li><span>结果正确</span><strong>输出值和题目要求一致</strong></li>
  <li><span>思路直接</span><strong>没有为简单问题增加无关代码</strong></li>
  <li><span>基础完整</span><strong>能组合容器、函数、文件和标准库</strong></li>
  <li><span>解释准确</span><strong>能说明引用和状态变化，而不是只猜输出</strong></li>
</ol>

<HighlightBox eyebrow="完成标准" title="会写基础代码，也能解释代码为什么这样运行">

</HighlightBox>
