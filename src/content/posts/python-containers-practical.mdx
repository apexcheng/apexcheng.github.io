## 字符串：先学会取、改、拆

SKU、订单号、状态、文件名、接口字段，绝大多数文本都是字符串。

```python
sku = "K161-PH"
```

### 用下标取单个字符

```python
print(sku[0])
print(sku[1])
```

输出：

```text
K
1
```

Python 的下标从 `0` 开始。

### 用切片取一段

```python
print(sku[:4])
print(sku[5:])
```

输出：

```text
K161
PH
```

`sku[:4]` 表示从开头取到下标 4 之前，右边界不包含在结果里。

### 清理字符串

外部数据经常带空格：

```python
raw_status = "  已支付  "
status = raw_status.strip()

print(status)
```

`strip()` 去掉两端空白。

常见字符串方法：

```python
text.strip()                  # 去掉两端空白
text.lower()                  # 英文字母转小写
text.upper()                  # 英文字母转大写
text.replace("旧", "新")     # 替换
text.split("-")              # 按分隔符拆成列表
```

例如：

```python
sku = "K161-PH"
parts = sku.split("-")

print(parts)
```

结果：

```text
['K161', 'PH']
```

注意这里发生了一个很重要的变化：**字符串经过 `split()` 后变成了列表。**

## 列表：一批有顺序的数据

```python
skus = ["K161", "K162", "K163"]
```

列表适合“多个同类数据”，而且有顺序。

```python
print(skus[0])
print(skus[-1])
print(len(skus))
```

输出：

```text
K161
K163
3
```

`-1` 表示最后一个元素。

### 添加和修改

```python
skus.append("K164")
skus[1] = "K162-A"

print(skus)
```

### 删除

```python
skus.remove("K163")
```

如果你知道位置，也可以用：

```python
del skus[0]
```

### 排序：需要有序结果时用 `sorted()`

```python
user_ids = [103, 101, 102, 101]
sorted_ids = sorted(user_ids)

print(sorted_ids)
```

输出：

```text
[101, 101, 102, 103]
```

`sorted()` 返回新列表，不修改原来的 `user_ids`。需要时还可以先用集合去重，再排序。

### 判断一个值在不在列表里

```python
if "K161" in skus:
    print("找到了")
```

这里先认识 `in`。下一篇条件分支会完整展开它怎样参与真假判断。

## 字典：一条数据的多个字段

```python
order = {
    "order_no": "A001",
    "sku": "K161",
    "amount": 129.0,
    "status": "已支付",
}
```

字典不是靠“第几个”取值，而是靠 key：

```python
print(order["sku"])
print(order["amount"])
```

输出：

```text
K161
129.0
```

可以直接修改或增加字段：

```python
order["status"] = "已完成"
order["shop"] = "旗舰店"
```

## `dict.get()`：处理外部数据时非常常用

如果 key 不存在：

```python
print(order["tracking_no"])
```

会抛出 `KeyError`。

如果这个字段本来就可能不存在，可以用：

```python
tracking_no = order.get("tracking_no")
print(tracking_no)
```

得到：

```text
None
```

也可以给默认值：

```python
tracking_no = order.get("tracking_no", "暂无物流")
```

处理 API 返回结果时，`.get()` 很常见。但业务上必须存在的字段不应无脑使用它，否则可能掩盖数据问题。

## 列表里放字典：真实数据最常见的组合

```python
orders = [
    {"order_no": "A001", "amount": 129.0},
    {"order_no": "A002", "amount": 88.0},
    {"order_no": "A003", "amount": 199.0},
]
```

现在取第二条订单的金额：

```python
print(orders[1]["amount"])
```

可以拆开看：

```python
second_order = orders[1]
amount = second_order["amount"]
```

这两步先从列表取出第二个字典，再按 key 取金额。长串取值看不懂时就拆成中间变量，入门阶段可读性比写成一行更重要。

## 嵌套数据：先一层一层取

接口数据经常更深：

```python
response = {
    "code": 0,
    "data": {
        "orders": [
            {"order_no": "A001", "amount": 129.0}
        ]
    }
}
```

一行写法是：

```python
order_no = response["data"]["orders"][0]["order_no"]
```

但新手更适合先拆：

```python
data = response["data"]
orders = data["orders"]
first_order = orders[0]
order_no = first_order["order_no"]
```

它们结果一样，但第二种更容易看见每一步的数据类型。

### 元组：知道“不能修改”就先够了

```python
point = (120, 30)
```

元组和列表一样可以按位置取值：

```python
print(point[0])
```

但元组不能像列表这样修改：

```python
point[0] = 100
```

会报错。

看到 `(a, b)` 时，先知道它可能是一个不希望修改的固定组合即可。

### 集合：去重和成员判断

```python
skus = ["K161", "K162", "K161", "K163"]
unique_skus = set(skus)

print(unique_skus)
```

集合会去掉重复值。

集合不适合按位置取“第几个”，主要用于：

- 去重。
- 判断某个值是否存在。
- 比较两组值之间的交集、差集。

如果你后面还需要稳定顺序，就不要把集合当成列表替代品。

### 两个变量可能指向同一个列表

```python
original = ["K161", "K162"]
copy_data = original

copy_data.append("K163")

print(original)
```

结果：

```text
['K161', 'K162', 'K163']
```

因为 `copy_data = original` 并没有创建新列表，只是让两个变量名指向同一个列表。

<figure class="py-reference-map" aria-labelledby="reference-caption">
  <figcaption id="reference-caption">两个变量名，共享同一个列表对象</figcaption>
  <dl>
    <div><dt>变量名</dt><dd><code>original</code></dd></div>
    <div class="shared-object"><dt>共同引用的列表</dt><dd><code>["K161", "K162"]</code></dd></div>
    <div><dt>变量名</dt><dd><code>copy_data</code></dd></div>
  </dl>
</figure>

如果只想复制外层列表：

```python
copy_data = original.copy()
```

现在 `copy_data.append(...)` 不会修改 `original` 的外层结构。

### 为什么浅拷贝仍会共享嵌套数据

看一个稍微进阶但非常值得提前知道的例子：

```python
original = {
    "name": "张三",
    "skills": ["Python", "SQL"],
}

copy_data = original.copy()
copy_data["name"] = "李四"
copy_data["skills"].append("Linux")
```

这里：

- 外层字典复制了，所以改 `name` 不会影响原字典的 `name`。
- 里面的 `skills` 列表却还是同一个对象，所以追加 `Linux` 会同时出现在两边。

这就是“浅拷贝”：**只复制最外层，里面嵌套的可变对象仍然可能共用。**

不要求现在掌握深拷贝规则，但不要把 `.copy()` 理解成“里面所有对象都彻底复制了一份”。综合考核会再次检查这个概念。

</details>

## 什么时候用哪一种结构

| 需求 | 优先想到 | 例子 |
| --- | --- | --- |
| 一段文本 | `str` | 订单号、SKU、状态 |
| 多个有顺序的同类值 | `list` | SKU 列表、订单列表 |
| 一条数据的多个字段 | `dict` | 一条订单、一个商品 |
| 固定组合，不希望修改 | `tuple` | 坐标、固定二元组 |
| 去重或快速判断成员 | `set` | 已处理订单号集合 |

真实脚本最常见的组合就是本文开头的结构：列表保存多条字典，每个字典里再保存字符串、数字或更小的列表。

## 动手练习：整理订单字段

从这份数据开始：

```python
orders = [
    {"order_no": " A001 ", "sku": "k161-ph", "tags": ["新品", "键盘"]},
    {"order_no": " A002 ", "sku": "k162", "tags": ["鼠标"]},
]
```

先不要写循环，直接操作第一条：

```python
first_order = orders[0]

order_no = first_order["order_no"].strip()
sku = first_order["sku"].upper()
sku_parts = sku.split("-")

print(order_no)
print(sku)
print(sku_parts)
print(first_order.get("tracking_no", "暂无物流"))
```

然后自己完成：

1. 给第一条订单新增 `status: "已支付"`。
2. 把 `tags` 里的内容转成集合，观察类型和输出。
3. 复制第一条订单，再修改复制结果的 `order_no`。
4. 解释为什么如果你修改复制结果里的 `tags` 列表，原数据仍可能变化。
