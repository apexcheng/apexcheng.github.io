不同来源的数据进入 Python 后，最终都会先变成字符串、列表、字典等基础对象，再进入前面已经学过的判断、循环和函数。

## 读取一个文本文件

假设当前目录里有一个 `order_no.txt`：

```text
A001
A002
A003
```

读取整个文件：

```python
with open("order_no.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)
```

先看关键部分：`open(...)` 打开文件，`"r"` 表示读取，`encoding="utf-8"` 指定文本编码，`file.read()` 把全部内容读成字符串。

`with` 是推荐写法，因为无论后面代码正常结束还是发生异常，文件资源都能被正确关闭。

## 一行一行处理文件

如果文件很大，或者本来就想逐行处理，不需要先把所有内容读成一个大字符串。

```python
with open("order_no.txt", "r", encoding="utf-8") as file:
    for line in file:
        order_no = line.strip()
        print(order_no)
```

这段代码把前面的知识串了起来：`for` 每次取得一行字符串，`strip()` 去掉换行和两端空白，最后得到干净订单号。很多数据清洗脚本就是这种结构。

## 写入一个结果文件

```python
result = ["A001", "A003"]

with open("result.txt", "w", encoding="utf-8") as file:
    for order_no in result:
        file.write(order_no + "\n")
```

`"w"` 表示写入。如果文件已经存在，会覆盖原内容。

如果希望追加到文件末尾，使用模式 `"a"`。写文件前要先确定是覆盖还是追加。

### 文件路径：先理解相对路径

```python
open("data/orders.txt", "r", encoding="utf-8")
```

这是相对路径。它不是“相对于 Python 文件本身”这么简单，而是相对于程序运行时的当前工作目录。

入门阶段最容易遇到的问题就是：文件明明在电脑上，Python 却说找不到。

可以先看当前工作目录：

```python
from pathlib import Path

print(Path.cwd())
```

`pathlib` 是 Python 标准库的一部分，不需要额外安装。

如果想构造路径：

```python
from pathlib import Path

file_path = Path("data") / "orders.txt"
print(file_path)
```

这里只先认识这种写法，不需要深入其他路径 API。

### `import`：使用 Python 自带模块

本文使用了 `import json` 和 `from pathlib import Path`。它们来自 Python 标准库，不需要额外安装：

```python
import json
json.loads(...)

from pathlib import Path
Path.cwd()
```

## JSON：接口和配置里最常见的数据格式之一

下面是一段 JSON 文本：

```json
{
  "code": 0,
  "data": {
    "orders": [
      {"order_no": "A001", "amount": 129.0},
      {"order_no": "A002", "amount": 88.0}
    ]
  }
}
```

它看起来很像 Python 字典，但它现在只是**一种文本格式**。

JSON 与 Python 常见类型的对应关系：

| JSON | Python |
| --- | --- |
| object `{}` | `dict` |
| array `[]` | `list` |
| string | `str` |
| number | `int` / `float` |
| `true` / `false` | `True` / `False` |
| `null` | `None` |

注意大小写：JSON 是 `true`，Python 是 `True`。

## JSON 的四个常用入口

先用一张表锁定输入和输出，避免只靠多一个字母 `s` 来死记：

| 函数 | 输入 | 输出或动作 |
| --- | --- | --- |
| `json.loads(text)` | JSON 字符串 | Python 对象 |
| `json.load(file)` | JSON 文件对象 | Python 对象 |
| `json.dumps(data)` | Python 对象 | JSON 字符串 |
| `json.dump(data, file)` | Python 对象和文件对象 | 直接写入 JSON 文件 |

### `json.loads()`：把 JSON 字符串变成 Python 数据

```python
import json

api_text = '''
{
  "code": 0,
  "data": {
    "orders": [
      {"order_no": "A001", "amount": 129.0},
      {"order_no": "A002", "amount": 88.0}
    ]
  }
}
'''

response = json.loads(api_text)

print(type(response))
print(response["code"])
```

输出：

```text
<class 'dict'>
0
```

`loads` 可以记成：**load string**，把 JSON 字符串解析成 Python 对象。

一旦解析完成，后面的操作就回到了上一篇学过的字典和列表：

```python
orders = response["data"]["orders"]

for order in orders:
    print(order["order_no"], order["amount"])
```

### `json.dumps()`：把 Python 数据变成 JSON 字符串

```python
import json

order = {
    "order_no": "A001",
    "status": "已支付",
}

text = json.dumps(order, ensure_ascii=False, indent=2)
print(text)
```

输出会类似：

```json
{
  "order_no": "A001",
  "status": "已支付"
}
```

这里：

- `ensure_ascii=False` 让中文直接显示，而不是变成 `\uXXXX`。
- `indent=2` 让 JSON 更容易阅读。

### JSON 文件：`load()` 和 `dump()`

如果 `orders.json` 本身就是一个 JSON 文件，可以直接：

```python
import json

with open("orders.json", "r", encoding="utf-8") as file:
    orders = json.load(file)
```

写入 JSON 文件：

```python
import json

with open("result.json", "w", encoding="utf-8") as file:
    json.dump(orders, file, ensure_ascii=False, indent=2)
```

## API 返回结果和 JSON 文件，本质上可以进入同一套处理逻辑

接口收到 JSON 后，同样会先解析成字典或列表，再取字段、遍历、筛选和调用函数。本系列暂时不引入第三方 HTTP 库，先把 JSON 与异常处理掌握即可。

## 为什么需要异常处理

真实数据不会永远干净。

上一篇学过：

```python
quantity = int("2")
```

正常。

但：

```python
quantity = int("两件")
```

会抛出 `ValueError`。

如果这个异常是业务里可以预期的，就可以处理它。

## `try / except`：只接住你明确知道可能失败的地方

```python
raw_quantity = "两件"

try:
    quantity = int(raw_quantity)
except ValueError:
    print("数量格式异常：", raw_quantity)
```

执行逻辑：

<figure class="py-error-branch" aria-labelledby="error-caption">
  <figcaption id="error-caption"><span>异常分支</span><strong><code>int(raw_quantity)</code> 只有两种明确结果</strong></figcaption>
  <dl>
    <div><dt>转换成功</dt><dd><strong><code>quantity</code> 得到数字</strong><span>回到正常处理路径</span></dd></div>
    <div><dt>发生 ValueError</dt><dd><strong>进入 <code>except ValueError</code></strong><span>记录问题，并在循环中跳过当前数据</span></dd></div>
  </dl>
</figure>

不要为了“程序永远不报错”把所有代码都塞进巨大的 `try`。只有明确知道某类失败可以怎样处理时，才接住它。

例如除数为 0 会抛出 `ZeroDivisionError`：

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("除数不能为 0")
```

重点不是背完异常名称，而是捕获当前操作对应的具体异常。

## 文件不存在：`FileNotFoundError`

```python
try:
    with open("orders.txt", "r", encoding="utf-8") as file:
        content = file.read()
except FileNotFoundError:
    print("没有找到 orders.txt")
```

它明确处理“文件不存在”，不会把编码错误、权限错误和代码 bug 全部吞掉。

## JSON 格式错误：`JSONDecodeError`

```python
import json

text = '{"order_no": "A001"'

try:
    data = json.loads(text)
except json.JSONDecodeError:
    print("JSON 格式不正确")
```

这里也一样：只处理自己真正理解的异常。

## 一个更完整的真实小案例

假设 `orders.json` 内容是：

```json
[
  {"order_no": "A001", "amount": "129.0", "status": "已支付"},
  {"order_no": "A002", "amount": "88.0", "status": "已退款"},
  {"order_no": "A003", "amount": "abc", "status": "已支付"}
]
```

目标：只统计已支付、并且金额可以正常转换的订单。

```python
import json

with open("orders.json", "r", encoding="utf-8") as file:
    orders = json.load(file)

total = 0

for order in orders:
    if order["status"] != "已支付":
        continue

    try:
        amount = float(order["amount"])
    except ValueError:
        print("金额异常：", order["order_no"])
        continue

    total = total + amount

print("有效已支付金额：", total)
```

<ol class="py-script-run" aria-label="真实订单脚本执行过程">
  <li><span>读取解析</span><strong>打开并解析 <code>orders.json</code></strong></li>
  <li><span>业务筛选</span><strong>跳过非已支付订单</strong></li>
  <li><span>数据校验</span><strong>金额转换失败时记录并跳过</strong></li>
  <li><span>结果汇总</span><strong>累计有效金额并输出</strong></li>
</ol>

## 本篇最容易混淆的四组概念

| 容易混淆 | 区别 |
| --- | --- |
| `read()` / `json.load()` | 前者读文本，后者直接读并解析 JSON |
| `json.loads()` / `json.load()` | 字符串 vs 文件对象 |
| `json.dumps()` / `json.dump()` | 得到字符串 vs 写到文件 |
| 正常分支 / 异常分支 | `if` 处理业务条件，`except` 处理执行失败 |

最后一条尤其重要。

例如“订单状态是已退款”不是异常，它只是一个正常业务状态，应该用 `if`。

“把 `abc` 转成数字失败”才是异常。

## 动手练习：读取并筛选订单 JSON

创建一个 `orders.json`：

```json
[
  {"order_no": "B001", "status": "已支付", "amount": "99.9"},
  {"order_no": "B002", "status": "已关闭", "amount": "120"},
  {"order_no": "B003", "status": "已支付", "amount": "bad"},
  {"order_no": "B004", "status": "已支付", "amount": "199"}
]
```

完成一个脚本：

1. 读取 JSON 文件。
2. 只处理 `已支付` 订单。
3. 金额转成 `float`。
4. 金额异常时打印订单号并跳过。
5. 最终输出有效订单数量和总金额。
6. 把两个结果写到一个 `result.json` 文件中。

如果能独立完成，这时你已经不是只会写课堂示例，而是在完成一个很小但完整的数据处理任务。
