# Python 实操练习包

这套练习与《Python 零基础到简单脚本》第 11 篇文章配套，包含原有 20 道基础练习，**不作为招聘正式考核使用**。

## 文件说明

- `python-basic-assessment.py`：原有 20 题脚本，在每道题的注释处填写自己的推理或代码。
- `test.txt`：第 12 题读取文件时使用的测试文本。

## 使用方式

1. 将 ZIP 完整解压到同一个文件夹，不要只打开其中的 Python 文件。
2. 在 Python 3 环境中打开 `python-basic-assessment.py`，阅读注释并完成题目；涉及预测的题先写答案再运行。
3. 第 12 题使用同目录的 `test.txt`，请保留文件名和相对位置。
4. 需要完整题目说明时访问：https://apexcheng.github.io/articles/python-basic-assessment-20-questions/

本包不含标准答案，也不附带评分或成绩汇总文件。正式能力考核请在 Python 系列目录下载独立的《Python 正式考核包》。
